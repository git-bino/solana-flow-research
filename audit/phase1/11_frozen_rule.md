## 1. Үгээр — чанга томьёолол

Токен бүрийн burst мөр бүрд:

1. **Дохио.** Burst `s` slot дээр илэрсэн (`nf5 ≥ max(3.0, 0.10·x)`, mayhem бус).
2. **Хүлээлт.** `L` = 8 slot хүлээнэ. Энэ хугацаанд захиалга газардаагүй.
3. **Гарах дүрэм нь `a ≥ 3`-аас ЭХЛЭН live.** `nf3(a) ≤ 0` болох **эхний** нас
   `a_exit`. (`a = 1, 2` нь trigger-ийн өөрийн slot агуулдаг тул тооцогдохгүй.)
4. **Орох нөхцөл.** Хэрэв `a_exit ≤ L` бол урсгал хүлээх хугацаанд тасарсан
   гэсэн үг — позиц **огт нээгдэхгүй** (арилжаа хийгдээгүй). Эс бөгөөс `s + L`
   дээр **`q` = 5 SOL**-оор орно.
5. **Гарах.** `s + a_exit` дээр бүрэн хаана (гарах latency `Lx` = 0).
6. **Хязгаар байхгүй.** Насны хязгааргүй (`A` = 75 нь зөвхөн траекторын урт),
   stop-loss байхгүй, `k` = 1.

> **Тэмдэглэл:** «`s+L` дээр `nf3 > 0` бол ор» гэсэн сул томьёолол нь **хангалтгүй** —
> `a_exit > L` нь `nf3(L) > 0`-ээс чанга. Сул нөхцөлөөр **34,862** мөр орох
> байсан, чангаар нь **5,402**.

## 2. Псевдокод

```
apply(nf3[1..75], excl1, excl2, x_end_slot, depth_x, L=8, q=5, Lx=0, pf=0):

    # гарах дүрэм, a >= 3-аас
    a_exit  <- min{ a in 3..75 : nf3[a] <= 0 }   (байхгүй бол 75, censored)

    if a_exit <= L:  return NOT TRADED

    # per-slot урсгалыг 3-slot гүйлгэх нийлбэрээс сэргээх
    f[1] <- excl1
    f[2] <- excl2 - excl1
    f[3] <- nf3[3] - excl2
    f[a] <- nf3[a] - nf3[a-1] + f[a-3]           for a = 4..75
    cum[a] <- sum(f[1..a]),  cum[0] = 0

    a_fill <- min(a_exit + Lx, 75)
    V <- cum[L]                                   # хүлээх хугацааны урсгал
    W <- cum[a_fill] - V + (x_end_slot - depth_x) # орсны дараах цэвэр урсгал

    # §5-ийн зам, шимтгэл 1.25%/тал
    x1 <- depth_x + V                             # ажиглагдах fill
    dy <- K/x1 - K/(x1 + q)
    x2 <- x1 + q + W
    out <- dy * x2^2 / (K + dy * x2)
    pnl <- out*(1 - 0.0125) - q/(1 - 0.0125) - 2*pf

    return TRADED, entry = L, exit = a_fill, pnl
```

`K` = x₀·y₀ = 30e9/1e9 × 1.073e15/1e6 SOL·tokens.
