## 3. ГОЛ АСУУЛТЫН ХАРИУ

**«`q = 0.05` дээр `fixed = 0.001` — ирмэг үхэх үү»** (одоо **хөл тутам** тул зардал **4.00%**):

| | хамгийн сул нүд | хамгийн хүчтэй нүд |
|---|---|---|
| `q = 0.05` дээрх яг E[ret] | **+34.70%** | **+69.58%** |
| `2 × 0.001 / 0.05` | −4.00% | −4.00% |
| **үлдэх** | **+30.70%** | **+65.58%** |

**Торын 25 / 25 нүд хоёуланд эерэг үлдэнэ.** Хамгийн хатуу нүд (`q = 0.05`, `fixed = 0.005`
хөл тутам = **20.00%** зардал): хамгийн сул **+34.70% → +14.70%**, хамгийн хүчтэй
**+69.58% → +49.58%**.

**Тэмдэг солих хил `q = 0.05` дээр:** хамгийн сул нүд **`fixed < 0.008675 SOL / хөл`**,
хамгийн хүчтэй **`fixed < 0.017395 SOL / хөл`** — даалгаврын торын дээд утгаас (0.005)
**1.7× ба 3.5×** дээгүүр.

> **Гэхдээ:** энэ нь **дундажийн** тухай мэдэгдэл. Бүх нүдэнд `median` **сөрөг**
> (−6.68% … −9.66%) ба `trim5` **сөрөг** (−5.88% … −11.49%) тул тогтмол зардал нь
> аль хэдийн алдагдалтай 79%-ийг улам гүнзгийрүүлнэ; дундажийн тэмдгийг өөрчлөхгүй,
> учир нь дундаж нь дээд децилээс гарч байна.
