## 1. Хөлдөөсөн дүрэм

`src/frozen_rule.py` — **хайлтын кодоос бүрэн хамааралгүй**: `fwd_net_ret`, `exit_latency`, `exploratory_search`-ийн аль нэгийг ч import хийхгүй. Траекторын рекурс ба замын арифметик дахин гаргагдсан; тестүүд нь `reconstruct_label` ба `cost_model`-той тулгадаг.

```
ОРОЛТ:  nf3_traj_75_incl_pre, nf3_excl_pre_1, nf3_excl_pre_2,
        x_end_slot, depth_x, параметр L
ГАРАЛТ: Outcome(traded, entry_slot, exit_slot, pnl, exit_age_rule, censored)
```

**Дүрэм:** burst-ийг ажигла, `L` slot хүлээ; гарах дүрэм **a ≥ 3-аас live** — `nf3(a) ≤ 0` болох эхний нас дээр гарна; хэрэв тэр нас `≤ L` бол позиц огт нээгдээгүй (**арилжаагүй**); эс бөгөөс `s+L` дээр `q` SOL-оор орж `a_exit` дээр гарна. Насны хязгааргүй, stop-loss байхгүй, `k = 1`.

Тогтмол: **`L` = 8, `q` = 5, `Lx` = 0, `pf` = 0**. Мэдрэмжийн зурвас: `L ∈ {1,3,8}`, `q ∈ {0.5,1,2,5}`, `Lx ∈ {0,1,3,8}`, `pf ∈ {0,0.001,0.01}`.

### Орох нөхцөлийн тодруулга — хэмжигдсэн

Даалгавар «`s+L` дээр `nf3 > 0` бол ор» гэж бичсэн. Операцийн дүрэм үүнээс **чанга**: гарах дүрэм 3-аас live тул 5-р насанд эргэсэн burst нь 5 дээр гарсан бөгөөд 8 дээр орох боломж байхгүй. `nf3(L) > 0` нь `a_exit > L`-ээс **улбаатай боловч түүнийг илэрхийлэхгүй**:

| нөхцөл | мөр |
|---|---|
| `nf3(8) > 0` дангаараа | **34,862** |
| `a_exit > 8` (операцийн) | **5,402** |

Зөрүү **6.5 дахин**. Операцийн уншлага нь хайлтын тоог давтдаг тул түүнийг авав.

### (в) Bootstrap-д ЯМАР нэгтгэл хангалттай вэ

Two-way кластер bootstrap дахь жин нь `w_i = m_token(t_i) × m_minute(m_i)` — хоёр кластерын үржвэр. Тиймээс жинтэй дундаж нь

```
expectancy = Σ_нүд m_tok(t)·m_min(m)·S(t,m)  /  Σ_нүд m_tok(t)·m_min(m)·N(t,m)
```

бөгөөд **(token, минут) түвшний P&L-ийн нийлбэр `S` ба тоо `N`** байхад bootstrap-ыг локал дээр бүрэн ажиллуулж болно. Батлав: нэгтгэлээс сэргээсэн expectancy нь шуудтай **1.11e-16** зөрүүтэй.

| | утга |
|---|---|
| Хэсэг 1-ийн арилжсан мөр | 5,402 |
| (token, минут) нүд | **5,324** |
| мөр / нүд | **1.015** |
| ялгаатай токен / минут | 5,033 / 4,250 |
| хэсэг 2–6 руу тэлсэн нүд | **≈ 22,545** |

> **Нүд бараг ганц мөртэй (1.015).** Тиймээс нэгтгэл нь шахалт бараг өгөхгүй — **(в′) арилжсан мөрийн P&L-ийг мөрөөр нь татах нь ижил үнэтэй** (415.5 vs 416.1 cr) бөгөөд дээд 1/5/10% хассан мэдрэмжийн шалгалтыг **бас боломжтой болгоно** (нэгтгэл түүнийг өгөхгүй). Энэ бол хэмжилт, зөвлөмж биш.
