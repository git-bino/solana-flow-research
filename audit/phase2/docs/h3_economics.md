## 0.1 Slippage — `cost_model.py`-ийн ЯГ ЗАМЫН АРИФМЕТИК

`sql/h3_economics.sql` нь `cost_model.net_pnl`-тэй **ижил хаалттай хэлбэрийг** (V = 0, pf = 0) бодно:

```
dy  = k/x₁ − k/(x₁+q)          →   энд k·q / (x₁·(x₁+q))   (алгебрийн хувьд ИЖИЛ)
x₂  = x₁ + q + W               →   x₁ = x_a, W = (r−1)·x_a  тул  x₂ = r·x_a + q
out = dy·x₂² / (k + dy·x₂)
pnl = out·(1−f) − q/(1−f)      f = 0.0125 ТАЛ БҮРД
```

`dy`-ийн дахин бичилт нь хоёр ~1e9 хэмжигдэхүүний **цуцлалтыг арилгана** — `cost_model` нь Decimal(60)
хэрэглэдгийн шалтгаан тэр цуцлалт. Гэвч «хангалттай» гэдэг нь **мэдэгдэл**, тиймээс хэмжив
(`src/h3_economics.py parity`, 0 credit, датаны бодит мужид):

| | |
|---|---|
| шалгасан цэг (x_a × r × q) | **351** |
| **хамгийн их харьцангуй зөрүү** | **1.669 × 10⁻¹⁴** |
| шимтгэлгүй, хөдөлгөөнгүй эргэлтийн хазайлт | **2.220 × 10⁻¹⁶** |

Цуваа задлаагүй, бага-`q` хязгаар аваагүй, шугаманчлаагүй — **ойролцоолол байхгүй**.

### 3.3 Хийгээгүй зүйлс ба хязгаарлалт

* **Overshoot тооцогдоогүй.** Win-ийг яг `1.20·x_a` (эсвэл `1.36·x_a`) дээр үнэлсэн; бодит давалтын
  мөчид `x` нь босгоос **дээгүүр** байж болно. `hpath` matview нь давалтын slot ба цагийг л
  хадгалдаг, тэр мөчийн `x`-ийг хадгалдаггүй. Энэ нь win-ийн үнэлгээг **доогуур** гаргана;
  хэмжихийн тулд шинэ forward pass хэрэгтэй. **Ажиллуулаагүй.**
* `V` (латенцийн урсгал) = 0, `pf` (priority fee) = 0 гэж авсан — `cost_model`-ийн анхдагч.
* Шинэ matview **үүсгээгүй**, parquet экспорт **хийгээгүй**.
* Загвар **барьсангүй**, шинж **сонгоогүй**, босго **тавиагүй**, дүгнэлт **бичээгүй**.
* Хэсэг 2–6 рүү **ороогүй**, `data/holdout/` **хоосон**, `decisions.md`-д **хүрээгүй**.
