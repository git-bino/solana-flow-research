### Эзэмшигчийн тоог хэрхэн тоолсон

Түрийвч нь **running balance > 0** үед эзэмшигч. Balance = (авсан − зарсан) + (хүлээн авсан − илгээсэн).
`seq = slot·1e9 + tx_index·1e4 + (outer_ix·64 + inner_ix)` нь арилжаа ба transfer-ийг **нэг дараалалд** оруулна.
`lag` **хэрэглээгүй** — event-ийн ӨМНӨХ үлдэгдэл нь яг `b − du` тул шилжилт нь
`+1` (b > 0 ба b − du ≤ 0), `−1` (b ≤ 0 ба b − du > 0); `n_holders` нь тэдгээрийн running sum. Нэг sort хэмнэгдсэн.

transfer **592,642 мөр** (885 токен).
