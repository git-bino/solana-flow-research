**Phase 3b рүү ороогүй · шийдвэр гаргаагүй**

## Сэргээлтийн гаргалт

`f(a)` = `s+a` slot дахь цэвэр урсгал. Extract-ийн гаргадаг зүйл:

```
nf3(a) = f(a−2) + f(a−1) + f(a)          (3-slot rolling нийлбэр)
excl_1 = f(1)                             (a=1 дээрх зөвхөн-урагшаа хэсэг)
excl_2 = f(1) + f(2)
```

Эндээс эхний гурав шууд гарна:

```
f(1) = excl_1
f(2) = excl_2 − excl_1
f(3) = nf3(3) − excl_2
```

`nf3(a) − nf3(a−1) = f(a) − f(a−3)` тул a ≥ 4 дээр:

```
f(a) = nf3(a) − nf3(a−1) + f(a−3)
```

Засварласан label = `Σ f(1..12)` — trigger-ийн slot-ыг **бүхэлд нь** хассан цонх.
