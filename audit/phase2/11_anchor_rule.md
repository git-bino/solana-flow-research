## 1. Дүрэм — үгээр

1. Токен бүрийн event-ийг `seq` дарааллаар алх, **transfer-aware** ledger хөтөл:
   `balance(w) = (авсан − зарсан) + (хүлээн авсан − илгээсэн)` — `oh_a`-тай ижил механизм.
   Түрийвч `balance > 0` үед **эзэмшинэ**.
2. **АНКОР** = эзэмшигчийн тоо анх **3** болсон event. Тэр event **ОРНО** — нөхцөл нь тэр
   event дуусахаас өмнө мэдэгдэхгүй (`ROWS … AND CURRENT ROW`).
3. **`x_a`** = тэр event **дууссаны дараах** нөөц. `virtual_sol_reserves` нь post-trade
   (`sql/phase0_kill_gate.sql`, 74,733 / 74,733). Transfer нь нөөцийг хөдөлгөхгүй тул
   сүүлийн арилжааны нөөц дамжина.
4. **Шүүлт:** (а) `t_anchor > 3 секунд`; (б) анкор дээрх `gini` (эсвэл `creator_share`) нь
   **доод терцилд**. Терцилийн хил нь **хөндлөн огтлолын** хэмжигдэхүүн тул `tertile_cut`
   параметрээр дамжина.
5. **ОРОХ** = анкороос хойших **3 дахь TRADE event**, тэр event-ийн дараах нөөцөөр үнэлэгдэнэ.
   3-аас цөөн trade event байвал → **арилжаа хийгдээгүй** (дүүрээгүй захиалга нь тэг ч биш,
   алдагдал ч биш).
6. **ГАРАХ** = `x ≥ x_a × 1.76` болсон эхний event-ээс хойших **3 дахь trade event**.
   Давалт байхгүй эсвэл дараа нь 3 event байхгүй бол → **сүүлийн арилжаа хүртэл барина**
   (censored).
7. **Зогсоол байхгүй.**
8. **Үнэ** `P = x²/k`, `k` тогтмол (mayhem **0 / 262,129**), шимтгэл **1.25% тал бүрд**,
   өөрийн үнийн нөлөө хоёр хөл дээр (`cost_model.net_pnl`), нэмэлт `fixed_cost` **хөл тутам** (хоёр удаа).

## 2. Псевдокод

```
anchor  := first i such that holders_after(i) >= 3
x_a     := reserve_after(anchor)
require  t(anchor) > 3.0
require  feature(anchor) <= tertile_cut          # REQUIRED; gini <= 0.267351881

entry   := 3rd trade event after anchor          # else NOT TRADED
x_in    := reserve_after(entry)

cross   := first j > anchor with reserve(j) >= x_a * 1.76
exit    := 3rd trade event after cross           # else last trade (censored)
x_out   := reserve_after(exit)

pnl     := net_pnl(x_obs=x_in, q, V=0, W=x_out-x_in, fee=0.0125/side,
                   fixed_cost_per_leg=fixed)   # charged TWICE
ret     := pnl / q
```

**Тогтмол:** `q = 1`, зорилт `+76%`, `entry_delay = 3`, `exit_delay = 3`, `t_N > 3 с`,
терцил доод, `fixed = 0`.
**Мэдрэмжийн зурвас:** `q ∈ {0.05, 0.1, 0.5, 1}`, зорилт `{+50%, +76%, +105%, +135%, зорилтгүй}`,
delay `{1, 3, 8}`, `t_N` бүлэг.
