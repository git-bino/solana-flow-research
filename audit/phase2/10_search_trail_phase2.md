## Эргэлтүүд — юунаас болж эргэсэн

| эргэлт | юунаас болж | өмнөх чиглэл яагаад унасан |
|---|---|---|
| **burst → hazard** | burst-ийн expectancy screening **futility**-ээр зогссон | 3b дэлгэц дээр нөлөө илрээгүй |
| **hazard → expectancy** | hazard муруй ялгаа өгсөн | — |
| **expectancy → `s`-д орох** | аудит 2 нь `causal_rule`-ийг **−0.168718** болгосон | entry reserve согог нь ашгийн **134.73%**-ийг үүсгэсэн байсан |
| **`s`-д орох → наслалт** | 11 хувилбар **бүгд сөрөг**, 120 нүднээс CI > 0 нь **0** | burst дээрх ямар ч орох цэг эерэг биш |
| **наслалт → токений хувь заяа** | ялгах чадвар байсан ч **ашиг биш**; хослол ганц шинжээс сул | AUC 0.5767 нь арилжааны ирмэг болоогүй |
| **токений хувь заяа → эрт таних** | `clean` **0.73%** — бүртгэгдсэн зогсох дүрэм | 99.16% нь rug; хувь заяагаар ялгах нь боломжгүй |
| **эрт таних → токен түвшний зам** | тархалт нь `x_growth`-ийн **хуулбар** (стратум дотор AUC унана) | шинэ мэдээлэл өгөөгүй |
| **зам → эзэмшигчийн анкор** | **60 хүрсэн токений 85.63% нь burst-ийн гадна**; `final_x ≥ 60` ердөө 20.42% | `x`-ийн түвшин анкор болоход хожил тасарсан |
| **эзэмшигчийн анкор → асимметр хаалт** | тэгш хэмтэй `+20/−20` дээр гүйцэтгэх нүд **−1.63% / −1.88%** | зорилт `x`-ийн 41/46 SOL дээр тасарч, 60/70/80 руу явдаг сүүлийг алдсан |
