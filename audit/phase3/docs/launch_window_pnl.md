## Блоклогч засвар — `a_exit <= latency` бол «арилжаа хийгдээгүй»

Орох захиалга нь дохионоос `lat` slot-ын дараа газардана; гаралтын дүрэм тэрнээс өмнө
эсвэл яг тэр үед ажиллавал позиц **огт нээгдээгүй**. Тэр мөрүүдийг хасаагүй, **тусад нь
тоолов**.

|---|---|---|---|
| **L1** | 1 | **0.00%** | [0.00%, 0.00%] |
| **L2** | 3 | **1.24%** | [0.00%, 56.17%] |
| **L3** | 8 | **91.87%** | [74.08%, 100.00%] |

**Бүх мөр нь арилжаагүй болсон багц: 144 / 2,160.** Эдгээр нь бүтцээрээ арилжих

өмнө байна.

## Яагаад эргээгүй — тоогоор

### latency: сонголтын нөлөө, шалтгаан нь тэмдэг биш

Ижил параметр (`k=1, A=75, L=∞, q=1, pf=0`) дээр гурван latency-г **тохирсон дээж** дээр
харьцуулбал:

| | арилжсан мөр | median (арилжсан бүх мөр) | **median (гурвуулаа арилжсан 5,402 мөр)** |
|---|---|---|---|
| **L1** | 126,089 (100.00%) | +0.009234 | **+0.266179** |
| **L2** | 56,327 (44.67%) | +0.018293 | **+0.194208** |
| **L3** | 5,402 (4.28%) | +0.008767 | **+0.008767** |

**Тохирсон дээж дээр чиглэл эдийн засгийн хувьд ЗӨВ — монотон буурах** (+0.266179 →
+0.194208 → +0.008767). Тохироогүй маргинал өсөж байгаа нь **сонголтын шилжилт**: L3-д
арилжигдсан 4.28% мөрийн L1 дээрх median нь **+0.266179**, бүх L1 мөрийн median нь
**+0.009234** — шилжилт **+0.256945**.

Өөрөөр хэлбэл latency нэмэгдэхэд «арилжаа хийгдээгүй» шүүлт нь **урт наслах burst-үүдийг
сонгож** үлдээдэг, тэр нь илүү сайн мөрүүд.

### `q`: масштабын нөлөө

`fwd_net_ret` нь абсолют SOL-оор илэрхийлэгддэг тул `q`-тай хамт томордог. Нэгж `q`-д
ногдуулбал:

| `q` | median-үүдийн дундаж (SOL) | **нэгж `q`-д (SOL/SOL)** |
|---|---|---|
| 0.5 | −0.000041 | **−0.000081** |
| 1.0 | +0.006081 | **+0.006081** |
| 2.0 | +0.015355 | **+0.007678** |
| 5.0 | +0.025040 | **+0.005008** |

Нэгжид ногдуулсан хэлбэр нь **монотон биш** (q = 2 дээр оргилдог), тиймээс SOL-оор өсөж
байгаа нь голдуу **масштаб**, эдийн засгийн сайжрал биш. Гэхдээ энэ нь «буурах» гэсэн
зөв чиглэл ч биш.

### `flow.event` ба `flow.token` нь ХООСОН

| хүснэгт | мөр | багана |

| `flow.event` | **0** | 22 (schema л байна) |

| шаардлага | төлөв |
|---|---|
| `createevent`-ийн slot `s0` | **ДУТУУ**. Гэхдээ 182 / 182 токены **эхний event нь яг x0-оос эхэлдэг**, тиймээс «эхний ажиглагдсан арилжааны slot»-ыг `s0`-ийн прокси болгож болно — энэ нь **create slot биш**, эхний арилжааны slot. |
| `createevent.creator` | **ДУТУУ, прокси байхгүй.** 3-р хэсгийн «үүсгэгчийн ашиг vs арилжаачны ашиг» задаргаа **боломжгүй**. |

| | |
|---|---|
| Эдгээр 182 токен `flow.burst_v2` (**хэсэг 1**)-д байгаа эсэх | **0 / 182** |
