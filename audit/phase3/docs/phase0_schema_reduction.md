## Засвар 1 — `nf3_traj_75_excl_pre` массив → хоёр скаляр

`nf3(a)`-ийн цонх нь `(s+a−3, s+a]` буюу slot `s+a−2 … s+a`. `a ≥ 3` үед хамгийн доод slot нь `s+1` тул бүх slot нь burst_slot-оос хатуу хойш → хоёр хувилбар давхцана. Хадгалагдах нь зөвхөн `a = 1, 2`.

## Засвар 2 — quote шүүлт

| | Хуучин | Шинэ |
|---|---|---|
| Create тал | `quote_mint IS NULL OR = SOL` | **`virtual_sol_reserves = 30000000000`** |
| Trade тал | `quote_mint IS NULL OR = SOL` | **шүүлт огт байхгүй** |
| `quote_mint` | шүүлт | **stratum багана** (§2.3) |

Trade талын шүүлт хасагдсан үндэслэл: токен нь `sel`-тэй join-оор аль хэдийн хязгаарлагдсан, ба `quote_mint` нь токен дотор тогтмол (248,657 токений 0 нь `MIN ≠ MAX`).
