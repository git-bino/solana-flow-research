## 3. Тоон тулгалт (1e−9)

### 3.1 Хоёр алгебр — зориуд өөр хэлбэр

Хуулбар таарц нь юу ч батлахгүй тул хоёр дахь хэлбэрийг **гаргаж** авав:

```
dy   = k·q / (x₁·(x₁+q))                      xe = x₁+q
out  = dy·x₂² / (k + dy·x₂)
     = [k·q/(x₁·xe)]·x₂² / (k·(1 + q·x₂/(x₁·xe)))
     = q·x₂² / (x₁·xe + q·x₂)                 ← k БҮРЭН ХАСАГДАНА
```

Эх хэлбэрт `k = 3.219e10` гурван удаа орно; өөр хэлбэрт **огт орохгүй**.

**Локал баталгаа (0 credit):** `cost_model.net_pnl`-тэй Decimal(60) дээр 252 цэг дээр
харьцуулав — **max |Δ| = 4.940e−57**.
