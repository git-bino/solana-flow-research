## 1. Дүрэм үгээр

**Универс (АУДИТ 4-ИЙН ДАРАА).** `createevent.is_mayhem_mode = false` — **launch-time**
ажиглагдах хэмжигдэхүүн. Хуучин `max|x·y/k₀ − 1| < 1e−6` нь бүтэн амьдрал дээр тооцогддог тул
анкорын мөчид мэдэгдэхгүй байсан. Шилжилтэд **437 токен** хасагдсан ба тэдгээрийн **нэг ч нь
H20 анкорт хүрээгүй** — анкорын түвшний бүх суурь тоо өөрчлөгдөөгүй.

**Анкор.** Event-үүдийг `seq` дарааллаар алхаж **transfer-aware** ledger хөтөлнө:
`balance(w) = (авсан − зарсан) + (хүлээн авсан − илгээсэн)`. `balance(w) > 0` бол эзэмшигч.
**АНКОР** = эзэмшигчийн тоо **20** хүрсэн эхний event; тэр event өөрөө тоологдоно (нөхцөл нь
дуусахаас өмнө мэдэгдэхгүй). `x_a` = тэр event-ийн **ҮЛДЭЭСЭН** нөөц; transfer нь нэгжийг
хөдөлгөх ба муруйг хөндөхгүй тул сүүлийн арилжааны нөөц дамжина.

**Шүүлт.** Анкорын 20 хэтэвчийн өмнөх `win_rate`-үүдээс
`B1` = **median**, `B2` = **90-р процентиль**; хоёулаа хөндлөн огтлолын **q5-ийн доод хилээс
дээш** байх ёстой.

**`win_rate`, lookahead-гүй.** D өдөр гарсан токенд хэтэвчийн өмнөх токен нь
**хуваарьт** ордог нөхцөл: тухайн хэтэвч түүн дээр анх арилжаалсан өдөр нь D-ээс **хатуу өмнө**.
**Хүртвэрт** ордог нөхцөл: `d_w = max(анх арилжаалсан өдөр, 60 хүрсэн өдөр)` мөн D-ээс
**хатуу өмнө**. D-ээс ХОЙШ 60 хүрсэн өмнөх токен нь хуваарьт орно, хүртвэрт ОРОХГҮЙ.

**Орох.** Анкороос хойших **3 дахь TRADE event**, тэр event-ийн үлдээсэн нөөцөөр үнэлнэ.
3-аас цөөн event бол **АРИЛЖААГҮЙ** (захиалга биелэхгүй; тэг ч биш, алдагдал ч биш).

**Гарах.** Аль нь эхэлж ирнэ:
зорилт = орохоос хойших `x ≥ 60` эхний event; хугацаа = анкороос **60 секунд**-аас хойших
эхний event. Яг тэнцвэрт **зорилт** авна. **Зогсоолгүй.**
Биелэлт нь нөхцөл хангасан event-ээс хойших **3 дахь TRADE event**-ийн үлдээсэн нөөц —
**overshoot** үнэ.

**Үнэ.** `P = x²/k`, шимтгэл **1.25% тал бүрд**, өөрийн slippage хоёр хөл дээр,
`fixed_cost_per_leg` — бүгд `cost_model.net_pnl`-ээр.

## 2. Псевдокод

```
if max|x·y/k₀ − 1| ≥ 1e−6:                      return NOT_CLEAN
bal ← {}                                        # transfer-aware
for ev in events sorted by seq:
    if ev is trade: last_x ← ev.x
    for (w, du) in ev.legs: bal[w] += du
    if |{w : bal[w] > 0}| ≥ 20:
        a ← ev; x_a ← last_x; holders ← {w : bal[w] > 0}; break
else:                                           return NO_ANCHOR

rates ← [win_rate(w, launch_day) for w in holders  if has history]
B1 ← nearest_rank(rates, 0.50);  B2 ← nearest_rank(rates, 0.90)
if rates is empty:                              return NO_WALLET_HISTORY
if B1 < b1_q5_lower or B2 < b2_q5_lower:        return FILTERED_OUT

entry ← 3rd trade event after a                 # else ENTRY_NEVER_FILLS
x_entry ← entry.x

g ← first trade event after entry with x ≥ 60
t ← first trade event after entry with ut − a.ut ≥ 60
trigger ← g if (g exists and (t missing or g ≤ t)) else t     # tie → target
fill ← 3rd trade event after trigger            # else exit at x_entry (fee-only)
x_exit ← fill.x

pnl ← cost_model.net_pnl(x_entry, q=0.5, V=0, W=x_exit−x_entry,
                         fixed_cost_per_leg=0.001)
ret ← pnl / 0.5
```
