## 1. Дүрэм үгээр

**Универс.** Зөвхөн цэвэр токен: токений өөрийн event дээр `max|x·y/k₀ − 1| < 1e−6`,
`k₀` = эхний event-ийн үржвэр. Инвариантаас гарсан токен нь **алдагдал ч биш, тэг ч биш** —
орчлонгоос гадуур.

**Анкор.** Event-үүдийг `seq` дарааллаар алхаж **transfer-aware** ledger хөтөлнө:
`balance(w) = (авсан − зарсан) + (хүлээн авсан − илгээсэн)`. `balance(w) > 0` бол эзэмшигч.
**АНКОР** = эзэмшигчийн тоо **20** хүрсэн эхний event; тэр event өөрөө тоологдоно (нөхцөл нь
дуусахаас өмнө мэдэгдэхгүй). `x_a` = тэр event-ийн **ҮЛДЭЭСЭН** нөөц; transfer нь нэгжийг
хөдөлгөх ба муруйг хөндөхгүй тул сүүлийн арилжааны нөөц дамжина.

**Шүүлт.** Анкорын 20 хэтэвчийн өмнөх `win_rate`-үүдээс
`B1` = **median**, `B2` = **90-р процентиль**; хоёулаа хөндлөн огтлолын **q5-ийн доод хилээс
дээш** байх ёстой.

**`win_rate`, lookahead-гүй.** D өдөр гарсан токенд хэтэвчийн өмнөх токен нь
**хуваарьт** ордог нөхцөл: тухайн хэтэвч түүн дээр анх арилжаалсан өдөр нь D-ээс **хатуу өмнө**.
**Хүртвэрт** ордог нөхцөл: `d_w = max(анх арилжаалсан өдөр, 60 хүрсэн өдөр)` мөн D-ээс
**хатуу өмнө**. D-ээс ХОЙШ 60 хүрсэн өмнөх токен нь хуваарьт орно, хүртвэрт ОРОХГҮЙ.

**Орох.** Анкороос хойших **3 дахь TRADE event**, тэр event-ийн үлдээсэн нөөцөөр үнэлнэ.
3-аас цөөн event бол **АРИЛЖААГҮЙ** (захиалга биелэхгүй; тэг ч биш, алдагдал ч биш).

**Гарах.** Аль нь эхэлж ирнэ:
зорилт = орохоос хойших `x ≥ 60` эхний event; хугацаа = анкороос **60 секунд**-аас хойших
эхний event. Яг тэнцвэрт **зорилт** авна. **Зогсоолгүй.**
Биелэлт нь нөхцөл хангасан event-ээс хойших **3 дахь TRADE event**-ийн үлдээсэн нөөц —
**overshoot** үнэ.

**Үнэ.** `P = x²/k`, шимтгэл **1.25% тал бүрд**, өөрийн slippage хоёр хөл дээр,
`fixed_cost_per_leg` — бүгд `cost_model.net_pnl`-ээр.

## 2. Псевдокод

```
if max|x·y/k₀ − 1| ≥ 1e−6:                      return NOT_CLEAN
bal ← {}                                        # transfer-aware
for ev in events sorted by seq:
    if ev is trade: last_x ← ev.x
    for (w, du) in ev.legs: bal[w] += du
    if |{w : bal[w] > 0}| ≥ 20:
        a ← ev; x_a ← last_x; holders ← {w : bal[w] > 0}; break
else:                                           return NO_ANCHOR

rates ← [win_rate(w, launch_day) for w in holders  if has history]
B1 ← nearest_rank(rates, 0.50);  B2 ← nearest_rank(rates, 0.90)
if rates is empty:                              return NO_WALLET_HISTORY
if B1 < b1_q5_lower or B2 < b2_q5_lower:        return FILTERED_OUT

entry ← 3rd trade event after a                 # else ENTRY_NEVER_FILLS
x_entry ← entry.x

g ← first trade event after entry with x ≥ 60
t ← first trade event after entry with ut − a.ut ≥ 60
trigger ← g if (g exists and (t missing or g ≤ t)) else t     # tie → target
fill ← 3rd trade event after trigger            # else exit at x_entry (fee-only)
x_exit ← fill.x

pnl ← cost_model.net_pnl(x_entry, q=0.5, V=0, W=x_exit−x_entry,
                         fixed_cost_per_leg=0.001)
ret ← pnl / 0.5
```

## 4. ⛔ КВИНТИЛИЙН ХИЛ — ТООГООР БЭХЛЭГДЭЭГҮЙ

`b1_q5_lower` ба `b2_q5_lower` нь `Params`-д **ЗААВАЛ** шаардлагатай (`None` дамжуулбал
`ValueError`) — `src/anchor_rule.py::Params.tertile_cut`-ийн ижил сахилга.

**Тоон утга нь ЭНЭ БАГЦАД БАЙХГҮЙ.** Тэдгээр нь `result_flow_pdhist2`-ийн засварласан
`wr_med` ба `wr_p90`-ийн **p80** (21,724 токен дээрх глобал mid-rank q5-ийн доод хил).
Локал кэшлэгдсэн ямар ч query үр дүнд p80 байхгүй — хэмжигдсэн нь зөвхөн квинтил доторх
median (`v50`), тэр нь хил БИШ.

Хилийг гаргахад **нэг Dune query** хэрэгтэй (хэмжигдсэн ойролцоо үнэ **≈ 0.05 cr**,
`b1_tautology` 0.043-тай ижил хэлбэр). Энэ алхам **0 credit** байсан тул хийгдээгүй.

**Хилийг holdout дээр ДАХИН БОДОХГҮЙ** — тэр нь lookahead. Хэмжилтийн дээжээс бэхлэгдэнэ.

## 8. МЭДЭГДЭЖ БУЙ СУЛ ТАЛУУД

1. **Cohort-цонхны хазайлт.** `B1` нь цонхны эхний өдөр тодорхойлогдохгүй: **2026-05-10-д
   мөр БАЙХГҮЙ**. **2026-05-11 нь 8/8 хослолд СӨРӨГ.** Эхний 3 өдөр vs сүүлийн 3 өдөр:
   **+0.0434 … +0.0566** зөрүү. Хожуу launch илүү түүхтэй — үр дүн энэ хазайлттай.
2. **30,903 үнэлгээ** хийгдсэн. Энэ нь олон удаагийн харьцуулалтын асар том орон зай.
3. **Кластер ердөө 9** (launch өдөр). Бүх CI энэ тооноос хамаарна.
4. **Median СӨРӨГ** (−0.0183) — дундаж нь сүүл дээр тогтсон. Эерэг арилжааны хувь 43.21%.
5. **Trim нь 83 эерэг хослолын зөвхөн 6-д** хийгдсэн (зардлын шийдвэр, үр дүн биш).
6. **H10 дээрх E[ret] / trim5 ГҮЙЦЭТГЭГДЭЭГҮЙ** (5.499 cr шаардана, үлдэгдэл 4.899 байсан).
   H10-ийн бүтцийн тоо (AUC 0.6187, `x_a` стратум 5/5) нь хийгдсэн.
7. **Зардлын 4.001 cr зөрүү ТОДОРХОЙГҮЙ:** гүйцэтгэл тус бүрийн `execution_cost_credits`-ийн
   нийлбэр 31.100 vs мөчлөгийн үлдэгдлийн зөрүү 35.101.
8. **Барих хугацааны max 68.9 хоног.** Гарах саатлын конвенц («нөхцлөөс хойш 3 дахь event»)
   **хугацааны тааз агуулаагүй**.
9. **Квинтилийн хил тоогоор бэхлэгдээгүй** (§4).
10. **Тоон тулгалт гүйцэтгэгдээгүй** (§5).
11. **Percentile-ийн конвенц ялгаатай:** Dune нь `approx_percentile` (t-digest),
    `b1_rule.py` нь **nearest-rank**. 20 элементийн ихэнх оролт дээр тохирно, бүгд дээр биш —
    нэрлэсэн parity эрсдэл.
12. **Биелээгүй гарах** нь `coalesce(x_ex_raw, x1)` буюу **шимтгэл-л төлсөн эргэлт** гэж
    үнэлэгдсэн (`unfilled_exit="entry_price"`). Энэ нь бодит эргэлт болсон гэсэн үг БИШ.
13. **`V = 0`, `pf = 0`** — өөр хүний урсгалын латенц тооцоогүй.
14. **`net_pnl` нь Dune дээр float64**, Python дээр Decimal(60); `dy`-ийн cancellation-гүй
    хэлбэрийн хэмжигдсэн parity 1.669e-14.
15. **Анкор transfer дээр буувал** орох event 3-аас арай хожуу (`result_flow_eg_entry`-тэй
    ижил конвенц).
16. **`win_rate`-ийн «өмнөх түүх» нь cohort цонхны доторх ШАЛ** — 2026-05-10-аас өмнөх
    pump.fun идэвх харагдахгүй.
