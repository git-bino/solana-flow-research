# Аудитын багц — Phase 3: `B1` ШҮҮЛТ БА ХӨЛДӨӨСӨН ДҮРЭМ

Бие даасан аудиторт зориулав. `audit/phase0/` дизайныг, `audit/phase1/` 19,627 тестээс нэг
дүрэм сонгосон явцыг, `audit/phase2/` 19,627 → 23,065 хүртэлх явц ба `anchor_rule`-ийг
шалгуулсан. Энэ багц нь **23,065 → 30,903 хүртэлх явц** ба `b1_rule` дүрмийг шалгуулах материал.

квинтилийн хилийн тоон утга, ба дүрмийн тоон тулгалт. Хоёулаа Dune-д хандахыг шаардана;
энэ алхам 0 credit байсан.
