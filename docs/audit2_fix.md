## 1. Засвар — causal execution clock

| | хуучин | **зассан** |
|---|---|---|
| Entry шийдвэрийн цаг | `s+L` (мөрийн дотор) | **`end(s+L)`** |
| Entry fill | `s+L` | **`s+L+1`** |
| Entry-ийн үнэ тогтох нөөц | `depth_x + cum[L]` | **`x_end_slot + cum[L]`** |
| Exit predicate мэдэгдэх | `a_exit` | `end(a_exit)` |
| Exit fill | `a_exit + Lx` | **`a_exit + 1 + Lx`** |
| `depth_x`-ийн үүрэг | үнэ тогтооно | **үнэд ОРОХГҮЙ** |
| Арилжааны хаалга | `a_exit > L` | `a_exit > L` (**өөрчлөгдөөгүй**, удирдагчийн сонголт) |

`x_end_slot − depth_x` нь trigger slot дотор, **захиалга оршин байх боломжгүй үед** газардсан урсгал. Хуучин дүрэм түүнийг post-entry ашиг болгож байсан. Одоо entry нь шийдвэр гаргах үед **бодитоор мэдэгдэж байгаа** нөөц дээр тогтоно; `cum` рекурс entry ба exit хоёуланд **ижил суурьтай** (`x_end_slot`).

> **Загварчлаагүй зүйл, ил бичив:** fill болох `s+L+1` slot доторх дараалал. Entry нь `end(s+L)`-ийн нөөц дээр тогтдог — тэр slot-ийн урсгалын аль нь ч бидний өмнө газардаагүй гэсэн таамаг. Эсрэг таамаг (бүгд өмнө газардсан) нь доорх stress cell. **ЭНЭ БОЛ CLAUDE CODE-ИЙН ШИЙДВЭР** — сонгохгүй, хоёуланг тайлагнав.
