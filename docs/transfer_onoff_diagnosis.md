### 2в. `pos`-ийн transfer мөчрүүд — кодоос мөрөөр батлав

```sql
-- transfer-OUT:  SELECT mint, from_owner AS wallet, ..., kind = 1,
--                d_units = -units,  d_units_buys = 0,  d_units_xf = 0
-- transfer-IN:   SELECT mint, to_owner   AS wallet, ..., kind = 2,
--                d_units = +units,  d_units_buys = 0,  d_units_xf = units
```

болохгүй. `run.kind` нь 0 / 1 / 2 гурван эх сурвалжийг зөв ялгаж байгааг өмнөх
даалгаварт хэмжсэн (илгээсэн хос 1,291, авсан 1,702, аль нэг 1,759).
