**`q`-ийн зөрүү, ил тэмдэглэв:** даалгаврын торны арифметик `q`-г **3** утгатай гэж тооцсон (3×5×4×3×3×3 = 1,620). Гэвч `spec.md:567` ба `src/cost_model.py`-ийн `Q_GRID` **хоёулаа {0.5, 1, 2, 5} буюу дөрвөн утга** нэрлэдэг. Баримтжуулагдсан торыг ашиглав, тиймээс торны тоо **1,620 биш 2,160**; хоёр reserve конвенцтэйгээ **4,320 үнэлгээ**. Олон-тестийн залруулгад энэ нь консерватив тал. **Аль торыг барих нь судалгааны удирдагчийн шийдвэр** — доорх нээлттэй асуултыг үзнэ үү.

### Дүрэм `a >= 3`-аас эхэлдэг — ил бичив

§3c-ийн хэмжилтээр `nf3_traj_75_incl_pre[a]` нь **s+a−2 … s+a** slot-ыг хамардаг тул **a = 1 ба a = 2 нь trigger-ийн өөрийн slot `s`-г агуулна**; hazard нь a = 3 дээр **0.017643 → 0.544678** үсэрдэг. a = 1-ээс эхэлбэл дүрэм trigger-ийн өөрийн худалдан авалтыг «урсгал эргээгүй» гэж уншина. Тиймээс **гурван дүрэм бүгд `FIRST_AGE = 3`-аас эхэлнэ**.

| дүрэм | хэрэгжүүлэлт |
|---|---|
| Урсгал эргэх | `nf3(a) <= 0` нь `k` дараалсан нас дээр; гарах нас нь `k`-дахь нь |
| Насны хязгаар | нөхцөл нь `a > A` тул гарах нас нь **A + 1** (A = 75 бол хэзээ ч ажиллахгүй) |
| Hard stop | `x(a) <= sqrt((1 − L) · x_eff · (x_eff + q))`, x_eff = `depth_x` + V |

Орох үнэ нь spec §5-ийн fill: `avg_price = x_eff(x_eff + q)/k`; нас `a` дээрх үнэ `x(a)²/k`. 75 нас хүртэл нэг ч дүрэм ажиллаагүй мөрийг **censored** гэж тэмдэглэж, a = 75 дээр албадан гаргаж үнэлнэ — **мөр хасаагүй** (хасалт нь survivorship үүсгэнэ).
