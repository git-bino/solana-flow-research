## 0. Царав, анкор, тодорхойлолт

**Цэвэр орчлон.** Mayhem дээр `P ∝ x²` хүчингүй ба зарагч нь AI агент тул «хэн зарж байна»
гэсэн асуулт утгагүй — тэдгээр токен **бүхэлдээ хасагдсан**.

**⚠ H30 БАЙХГҮЙ.** `result_flow_holder_anchor` нь H3 / H5 / H10 / H15 / H20 / X60-ыг л агуулна.
H30 нэмэх нь **running holder count** дамжлага шаардана — тэр нь **24.466 cr**, энэ алхмын бүх
бюджетээс их. **H30 хэмжигдээгүй, ойролцоолоогүй.** Ажиллуулсан нь **H15 ба H20**.

**Урьдчилж тогтоосон тодорхойлолт.** Уналт = анкороос хойш `x ≤ 0.90 × x_a` болсон **эхний**
event. Ангилал: `CREATOR` = createevent-ийн creator; `EARLY` = анкор дээр `held_units > 0`
байсан; `LATE` = анкорын дараа анх эзэмшигч болсон. Ledger **transfer-aware**.
