## 1. ClickHouse ачаалалт — `flow.burst_v2`

`flow.burst` (v1, 60 багана, 667,809 мөр) **хөндөөгүй** — аудитын мөр уншигдахаар
үлдэнэ; v2 нь дэргэд нь тусдаа хүснэгт.

```
ENGINE = MergeTree
ORDER BY (token_mint, slot, tx_index, outer_ix_index, inner_ix_index)
CONSTRAINT traj_len_75 CHECK length(nf3_traj_75_incl_pre) = 75
```

80 багана = `CANON_V2`. Arrow → ClickHouse: `large_string`→`String`,
`int64`→`Int64`, `double`→`Float64`, `bool`→`Bool`, `list<double>`→`Array(Float64)`.
Бүтэн DDL: `sql/clickhouse_burst_v2.sql`.

**Nullable нь 4 багана** — `quote_mint`, `death_age_slot`, `death_age_incl`,
`death_age_excl`. `CANON_V2` нь 80-уулаа nullable гэж тэмдэглэдэг (Arrow-ийн анхны
утга), үсгээр нь дагавал sorting key ч Nullable болно. Бодит NULL-ыг хэмжиж
зарлав; ачаалалтын дараах assert нь багана тутмын NULL-ыг parquet-тэй тулгадаг.

Timestamp-ийн бүх харьцуулалтад **`'UTC'` бэхлэгдсэн** (server нь
`Asia/Ulaanbaatar`; v1-д бэхлээгүйгээс 6,562 сайн мөр худал унасан).
