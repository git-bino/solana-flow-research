## 4. `ix_index` packing

### Raw `outer` / `inner` кэшэд **БАЙХГҮЙ**

Кэшийн талбарууд: `is_buy, ixi, lam, mint, slot, txi, units, vsol, wallet, x0_lam,
y0_units`. `ixi` нь аль хэдийн **савласан** утга (`outer × 64 + inner`); анхны
`evt_outer_instruction_index` / `evt_inner_instruction_index` хадгалагдаагүй.

**а–в (inner/outer-ийн max, тархалт, NULL хувь) нь локалаар хэмжигдэхгүй —
2026-08-31-нд Dune дээр хэмжигдэнэ.**

### г. Савласан түлхүүрийн collision — локалаар хэмжигдэнэ

| | |
|---|---|
| `(mint, slot, tx_index, ix_index)` дээрх collision | **0 / 15,017** |
| `ix_index` min · p50 · p90 · p99 · max | 67 · 260 · 329 · 521.84 · **839** |
| 64-ийн үржвэр байх хувь | **0.000%** |
| Савлалт биелнэ гэж үзвэл implied `inner` max | **41** |
| Савлалт биелнэ гэж үзвэл implied `outer` max | **13** |

64-ийн үржвэр огт байхгүй нь `inner ≥ 1` үргэлж үнэн гэсэн үг — TradeEvent нь
self-CPI-аар ирдэгтэй нийцнэ.

> **implied `inner` max = 41 нь overflow БАЙХГҮЙ гэдгийн нотолгоо БИШ.** `inner ≥ 64`
> байсан бол савласан утга өөр `outer` руу шилжиж, савласан тооноос ялгагдахгүй болно.
> Энэ мөрийг зөвхөн Dune дээрх түүхий `inner`-ээр шийднэ. Локал дээр батлагдсан цорын
> ганц зүйл нь **энэ 15,017 event дээр савласан түлхүүр давхардаагүй** гэдэг.
