# MATERIALIZED VIEW-ээр материалчлах (2026-08-20)

Өмнөх оролдлого `query_<id>` нь **view** гэж тогтоогоод зогссон. Судалгааны удирдагчийн
вэб хайлтаар Dune-д жинхэнэ MATERIALIZED VIEW байдаг нь тодорхой болсны дараа
үргэлжлүүлэв.

## 1. Механизм

### 1а. API endpoint — туршиж олсон

Баримтжуулалт уншигдаагүй (вэб хандалт байхгүй), тиймээс endpoint-ийг **хариултын
алдааны мессежээр** олов:

| дуудлага | хариу |
|---|---|
| `GET /api/v1/materialized-views` | **200** `{"materialized_views":[]}` |
| `GET /api/v1/materialized_views` | 404 |
| `GET /api/v1/query/<id>/materialized-view` | 404 |
| `POST /api/v1/materialized-views` `{}` | 400 `Query not found` |
| `POST` `{"query_id": N}` | 400 **`invalid name: , must have result_ prefix`** |

Бүрэн гадаргуу:

```
POST   /api/v1/materialized-views          {"name": "result_<нэр>", "query_id": N}
                                           -> {"name": "dune.<user>.result_<нэр>",
                                               "execution_id": "..."}
GET    /api/v1/materialized-views          жагсаалт: sql_id, query_id, is_private,
                                                     table_size_bytes
GET    /api/v1/materialized-views/<sql_id> дээрх + last_execution_ids
POST   /api/v1/materialized-views/<sql_id>/refresh
DELETE /api/v1/materialized-views/<sql_id>
```

`<sql_id>` нь **бүтэн** `dune.<user>.result_<нэр>` байх ёстой; богино нэр 400 буцаана.
Үүсгэх нь query-г шууд **ажиллуулдаг** — буцаах `execution_id` нь тэр байгуулалт.
